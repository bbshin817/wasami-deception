## 決定事項

- 2026-09-16 18:25: **色味の差の主因は `M_DD_Substance` のコンパイル失敗**と判断し、計画を「失敗を直す → 焼き直す → 残りを切り分ける」に変えた — 実機の開始地点の絵と本作の `zone1-start-pie-baked.png` を並べると、本作は壁も床も灰色の市松（`DefaultMaterial`）で、金属の壁・床の赤い帯が出ていなかった。ログには `Failed to compile Material Instance with Base M_DD_Substance for platform PCD3D_SM6, Default Material will be used in game.` が 814 件あり、理由は全件 `(Node TextureSampleParameter2D) Sampler type is Linear Color, should be Masks for /Game/Pipeline/Textures/T_DD_DefaultPacked`。グラフは Packed を `SAMPLERTYPE_LINEAR_COLOR` で作るのに、既定テクスチャだけ `TC_Masks` で取り込んでいた（どちらも最初の取り込みのコミット `b2c4333` から）。焼く前の Lumen の絵（`zone1-start-pie.png`・`zone1-corridor-pie*.png`）にも市松が出ているので、これまでの色の比較はすべてこの状態のもの。Lightmass も既定のマテリアルを反射率に使って焼いたはずなので、直したら焼き直す。
- 2026-09-16 18:25: Packed は **`LINEAR_COLOR` の側に揃える**（既定テクスチャを `TC_Default`・リニアにする） — 原作の Packed テクスチャは `stage_ue.json` で 85 個が `TC_Default`・リニア（sRGB 10 個・`TC_Normalmap` 1 個）で、`TC_Masks` は 0 個。サンプラーを Masks にすると原作のテクスチャの側と合わない。
