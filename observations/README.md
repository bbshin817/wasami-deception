- **テレキネシス**（b、速さ 1）: 使って約 0.2 秒は水色の白飛び（(86, 222, 240) → (152, 218, 238)）、〜1.1 秒は青（(90, 141, 192) → (51, 67, 81)）、1.28 秒で元に戻る。a / c（0.25）では、白飛びの後に力場（青紫の半透明の幕が画面を覆ってうねり、水色の星屑が散る。地面の輪は床の奥に見える）が約 3.6 秒（実時間で約 0.9 秒）見える。**力場の間、廊下が白や水色に照らされる様子は見えない**（中央の平均は幕の青 (135〜160, 190〜200, 230)）。
- **Primal Fear**（0.25）: 黄〜橙の白飛び（(227, 119, 51) → (239, 154, 132)。星状の粒の模様が画面に乗る）が約 0.7 秒、次に赤の単色（(79, 29, 30)）が薄れて約 1.7 秒で戻る（実時間で約 0.18 秒と 0.43 秒）。途中で縮む球が縁の明るい赤い箱のように見える。
- **Vanish**（0.25）: 桃〜白の白飛び（(244, 195, 247)）→ 紫 (79, 41, 110) → 廊下に紫のもや（中央 (115, 90, 148)）が約 3.9 秒で薄れる。左右の縁に紫の揺らぐビネットが残り、明るさが約 5.1 秒周期で脈打つ（全体の G 64 ↔ 67。材質の時間が slomo で遅くなるなら実時間で約 1.3 秒。UI の材質の時間が slomo に従うかは未確認）。
- **Telepathy**（b）: Reaper Nurse の体の上に、体と同じくらいの大きさの**橙〜赤の炎のような印**が重なる（使って約 0.7 秒から、捕まるまで）。
- **シャードの回転**: 45 秒のフレームの差が**ずれ 21.0 秒で極小**（13.6。ずれ 0 は 6.3、ほかは 17〜20）。1 周が 21 秒なら 17.1 °/s（本作の「1 ループ 2 周」の読みの範囲 10.8〜32.4 °/s に入り、「1 周」の読みの 5.4〜16.2 °/s からは外れる。結晶が 2 回対称なら 8.6 °/s でどちらにも入らない）。
- **テレポートの照準**（Lv3）: 赤〜サーモン色の渦の輪（中心は白っぽい）、内側に赤いデカールの光、小さな赤い火花が数個。**デカールは約 1.0 秒周期で明滅し、内側の中央値の R が 139 ↔ 238（G 81〜98、B 81〜90）**。すぐ外の床は (78, 89, 102)。
- **倍率 25 のシェイクの間の黒いフレーム**: Primal（a・b）とテレキネシス（a・c）の画面の下半分で、ほぼ黒（< 8）の画素は最大 7 %（172 × 72 に縮めた絵の輝度。原寸の輝度で測る `python Tools/video_probe.py series <mkv> --dark 8` では primal-a 0.099・primal-b 0.075・telekinesis-a 0.045。PIE と比べるときはこちらの値を使う）。**タブレットが横切る黒いフレームは見えない**（0.25 倍で 1 秒 10 枚 = 実時間で約 40 枚相当）。
- 回収の音の重なりは音を撮っていないので分からない（人が聞いて確かめる）。
