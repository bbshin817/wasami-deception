## 本家の作り（2026-09-19 に読んだもの）

読み方は `python Tools/dd/bp_flow.py <file> <イベント名 | 番地>`。ナースは `pak_reference_2/_bytecode/DDeception/Content/Blueprints/Characters/Nurse/`。**行動ツリーは無い**（BP の `Make Choice` と `AI MoveTo` だけ）。

- **`BP_06_ReaperNurse`**（実装記録 07 の `AWasamiEnemy` が CDO・部品・気絶を持つ）:
  - `BeginPlay`: `Generate Random Point` → `Make Choice` を 0.5 s ごと（`DecisionTimer`）→ 0.2 s 後 `Ignore All Speed Barriers`。
  - `Make Choice`（@7107）: State == 2 → 気絶（済み）。`bThrowing`（薬。作らない）なら何もしない。それ以外は **先に** `Seen Player Recently` を見て、真なら `Chase Player` → `RetriggerableDelay(3)`（明けたら `Seen` = 偽・`Reset Detection`）、偽なら `Not Seeing Player`。**その後で** `Can See Player` が真なら `Seen` = 真。最後に `Distance To Player > 1500` で透明化（作らない）。
    - 読み: `Seen` が真の間は判断ごとに 3 s の遅延が掛け直されるので、自分からは見失わない。見失うのは `Player Vanish`（`Seen` = 偽）と、判断が止まる気絶（3 s で明ける）だけ。**ステップ 2 で bytecode の順（@7172〜@7523）をもう一度確かめる**。
  - `Can See Player`: 前 と プレイヤーへの向きの角度 < **100°**（距離の上限なし）かつ `LineTraceSingle(自分の位置 → プレイヤーの位置, TraceTypeQuery ByteConst 1 = Camera, 複雑 真, 自分を除く)` の当たりがプレイヤーのキャラクター。
  - `Chase Player`（@7524）: `Seen` = 真、`Point Of Interest` = プレイヤーの位置、`Set Walk State(偽)`（800）、`CreateMoveToProxyObject(目標 = Player Target()〈プレイヤー〉, 受け入れ半径 5, bStopOnOverlap 偽)`（成功・失敗とも何もしない）、DoOnce: 発見の台詞（項目 20）と `CloseBy` を放つ（`Reset Detection` で開く）。DoOnce + 5 s → 見ていれば薬投げ（作らない）。
  - `Not Seeing Player`（@7940）: `Point Of Interest` == 0 なら `Random Point Destination()`（`Random Point`）へ受け入れ半径 50 で移動・`Set Walk State(真)`（350）、着いても失敗しても `Generate Random Point`。0 でなければ `Point Of Interest` へ半径 5 で移動・歩き、着いても失敗しても `Point Of Interest` = 0。
  - `Generate Random Point`: プレイヤーがいればプレイヤーの位置、いなければ自分の位置の周り **3000** の `K2_GetRandomReachablePointInRadius`。
  - `ReceiveTick`: スケートの音（作らない）だけ。`ReceiveHit` は空。`Get State` は常に 0、`Chasing` = `Seen`、`Get Frenzy` = 偽、**`Activate Frenzy` は実装していない**。
- **`BP_06_ReaperNurse_06_Chase`**（Zone 1 の 06。`Spawn Nurses_06` が `06_NurseSpawn`・`06_NurseSpawn2` に出し `Door Location` を渡す）: 毎ティック `Chase Player`（気絶中は 17 s 止まる）。`bAttackDoor` の間は針で扉を突くモンタージュを繰り返し（終わるたびに 0〜0.5 s）、通知で 50 % `Hit FX`（`P_06_NurseDoorHit` を 0.5 倍・`Audio`・`01_Hotel_Lobby_ElevatorShakeStop` 0〜3000）。`Chasing` = 真。薬・透明化は空。
- **`BP_06_ReaperNurse_Zone2`**（Zone 2 の迷路。`Spawn Nurses` が `NurseSpawn_4`・`_1`・`_2` に出す）: `is Up?` = 自分の Z > 640、`is Player Up?` = プレイヤーの Z > 610。同じ階でなければ `Player Target` と `Random Point Destination` を、最も近い `BP_06_LiftBase` とその `Move Location` の位置に替える（`MoreporkFunctions.GetFurthestOrClosestActor` の引数の意味はステップ 4 で読む）。
- **`BP_06_ReaperNurse_Sentry`** ×6（Zone 2 のミニボスの廊下。レベルに置かれ `CanSpawn` 真、`bAggressiveIdle`、`Initial Yaw`・`Offset`・子の `Viewcone`〈`BP_06_Miniboss_viewcone_Nurse`〉・`Jump Down Spot`）: `BeginPlay` は空（判断しない）。レベル BP の `Activate MiniBoss Enemies`（`Miniboss Transition` から）が全員の `Activate` → 視界コーンの `Offset` を入れて `Initialize`。視界コーンの `Player Spotted` → DoOnce: 視界コーンを消し `Chasing` = 真、`Jump Down Spot` への向き × 400 と上 500 で `LaunchCharacter` → 親の `BeginPlay`（普通のナースになる）。`Start/Stop Looking` は `bVarIdle`。
- **視界コーン** `Blueprints/06_Hospital/Miniboss/BP_06_Miniboss_viewcone`（+ `_Nurse`。項目 11 の Matron も `_Matron_Long`・`_Short` で使う）: `Initialize` → `Update Sight` を 0.3〜0.5 s ごと。初回だけ `Offset` 秒待つ。`Player Inside Cone?`（`bOn`・距離 < `Length`・角度 < `Angle`）かつ `Player In Full View?`（Camera の線がプレイヤーに届く・距離 ≤ `Length`）→ DoOnce で親の `Player Spotted`。`Turn On`（親の `Start Looking` → 1 s → `bOn` 真・板の `Fade In`）/ `Turn Off`（`Stop Looking`・`bOn` 偽・`Fade In` を戻す）。`_Nurse` は `Initialize Finished` から 10 s ごとに `Turn`（点く ↔ 消える）。`Length`・`Angle` などの値と板の材質は `_assets/…/Miniboss/*.json`。
- **レベル**（`pak_reference_2/_levels/06_Hospital_Zone_0*.full.json`）: 出現点は `TargetPoint`。Zone 1: `NurseSpawn_1` (5390, −7205, 60)・`_2` (−5405, −7205, 60)・`_3` (70, −11140, 60)、`06_NurseSpawn` (3375, −23105, 35)・`06_NurseSpawn2` (3375, −23700, 35)、ガレージリフトの `TriggerVolume_1`（`Check Lift Nurses`。ナースが入るとリフトの `NurseNear`）。Zone 2: `NurseSpawn_1` (11446, −2026, 84)・`_2` (15513, −3862, 84)・`_4` (8823, 3199, 84)、見張り `ReaperNurse_Idle_Alert3`〜`7`・`_Alert_5`（Z 約 430〜450 の高い所）。
- **NavMesh**: `RecastNavMesh-Default` は `AgentRadius` 40・`AgentMaxHeight` 144（ほかは既定）。`NavMeshBoundsVolume` は Zone 1 に 2、Zone 2 に 29、`NavModifierVolume` は Zone 2 に 30（`AreaClass` の書き出しなし = 既定の `NavArea_Null`）。**ブラシの形は書き出しにある**: 各ブラシの `BodySetup` の `AggGeom.ConvexElems` が ±100 の立方体で、`BrushComponent` の `world` が位置・回転・拡縮（ほかのボリュームと同じ。`Tools/dd/prepare_stage.py` の `brush_volume` が読む形）。
- **全回収**: ゲームモードの `Event All Shards` は敵に `Activate Frenzy` を呼ぶが、ナースは実装していない。レベル BP は Zone 1 の `05 All Shards Collected`・Zone 2 の `Postmaze Transition` で `Remove All Enemies`（本作も項目 6 で同じ）。Nightmare のナース `BP_06_ReaperNurse_06_Chase_Nightmare` を使うのは入口 `06_Hospital`（作らない）だけ。
