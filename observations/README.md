**`capture_pose` の絵は絶対の明るさの比較には使えない**（`SceneCapture2D` は Lumen の間接光を本編と同じには回さず、同じ視点の PIE より暗く出る）。設定 A と設定 B を同じ視点で比べるのには使える。

残る差は**色温度**。青が 25 に対し実機は 39 で、本作のほうが黄緑に寄っている（露出ではなく灯・スカイライト・反射キャプチャの側の課題）。
