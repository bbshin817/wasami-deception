# 画面（死亡画面・SAVING PROGRESS・黒のフェード）

## 役割
ゲームの流れの画面。本家の最新版 `pak_reference_2` の次の 4 つ:
- **死亡画面**（`Blueprints/UMG/UMG_DeathScreen`）: 黒地にライフの列、REMAINING LIVES とヒント、その上の黒い覆いの Fade In / Fade Out、失ったライフが赤く揺れて列から消える Shake。ライフが 0 なら YOU ARE DEAD と 3 つのボタン（RESTART / LAST CHECKPOINT / QUIT TO TITLE。ホバーで白くなり、押すと黒くなってレベルを開く。RESTART と、はじめての LAST CHECKPOINT は先に問う）。ライフが残っていれば、終わりにプレイヤーのパワーをリセットして今のレベルを開き直す。
- **YES / NO の問い**（`UI/Main/TitleScreen/UMG_PopUp`）: 画面全体の赤いぼかしの上に、ポーズの窓の枠と問い・YES・NO が拡大しながら現れる。死亡画面の RESTART と LAST CHECKPOINT が使う（タイトル・ポーズでも使う部品）。
- **SAVING PROGRESS**（`UI/Main/UMG_Saving`）: チェックポイントの保存で右下に 3 秒出る文字と丸。
- **黒のフェード**（`Blueprints/UMG/UMG_BlackFade_2`）: 黒い全面が消えていく（か現れる）。ゲームモードがレベルを開くたびに 0.5 秒で黒から明ける。

出す側はゲームモード（`DeathEvent` が死亡画面、`SaveCheckpoint` が SAVING PROGRESS、`BeginPlay` がフェード。02・06 記録）。タイトル・ポーズ・脱出の画面・字幕はこれから。原作の流れの調べは `.claude/references/game-flow/README.md` の「死亡画面」「SAVING PROGRESS」。

### Construct（`NativeConstruct`）
- ゲームインスタンスの `DecrementLives` → 残りのライフ。ゲームモードのセーブ（`GetSave()`）の `Hospital.Deaths` +1・`CurrentStreak` = 0 を `WriteSave`。`LevelCheckpoint` > 0 を LAST CHECKPOINT を出す条件として持つ。
- ヒント: `TipsFor(GetCurrentLevelName)` から無作為に 1 つ。Zone 1（名前に `Zone1`）は 3 本、Zone 2（`Zone2`）は 4 本、ほかは「Try not to die next time.」。文言は本家の `Set Tip` のまま（後ろの空白も）。
- 声: `VoiceLengths(Level)` から無作為に 1 本の長さ（本家の Bierce の台詞の `Duration`。Traps 7 本・Asylum 4 本）。**鳴らさず、その長さだけ待つ**（声は作業一覧の項目 20）。
- `Begin(残り, 声の長さ, チェックポイントの有無)`。

### 時間の流れ（`Begin`・`Advance`・`RunStep`）
本家の Delay を「いつ・何をするか」の予定（`Pending`）で持ち、`Advance` がアニメを先に進めてから、期限の来た予定を早い順に走らせる（UE のユーザーウィジェットはアニメの後に遅延を処理する。遅延が始めたアニメは最初のコマをすぐ描く）。予定の遅延は、その予定が来るはずだった時刻から数える。時刻は `Begin` からの秒で、ウィジェットのティック（ゲームを止めていても進む実時間）で進む。
- 0.5 s（`LifeLost`）: ライフ > 0 なら `Life_Lost`（0.6）。
- 0.5 s（`Reveal`）: Fade In を 1.5 倍速で。
  - ライフ > 0: 声の長さの後と 6 s 後に `Proceed`（DoOnce）。`Life Animation`（添字 `ライフ + 1`〜5 のアイコンを列から外し、外したら 1 s 後に `Shake`。ライフ 5 以上なら何もしない）。
  - ライフ 0: チェックポイントが無ければ LAST CHECKPOINT を外す。ライフの列・見出し・ヒントを隠し、0.25 s 後に `GameOver`。
- `Shake`: Shake を再生し、0.1 s のイベントで `Update Life`（添字 `ライフ` のアイコン = 失った 1 つを外す。列は中央に詰まる）。
- `Proceed`: 最初の 1 回だけ。ライフ > 0 なら 0.5 s 後に `FadeOut`。
- `FadeOut`: Fade Out を再生し、2 s 後に `Respawn`。
- `Respawn`: プレイヤーの `GetPowers()->ResetPowers()`、`OnRespawn`、`OpenLevel(今のレベルの名前)`。ワールドが無い（テスト）ときは `OnRespawn` だけ。
- `GameOver`（0.75 s）: `66_-_Game_Over`（0.7）、Death を再生、`SetInputMode_UIOnlyEx`（この画面にフォーカス、マウスは閉じ込めない）、2 s 後に `Buttons`。
- `Buttons`（2.75 s）: RESTART・QUIT TO TITLE と（残っていれば）LAST CHECKPOINT を `Visible`、マウスカーソルを出す。

### ゲームオーバーの 3 つのボタン
本家の 3 つの道は DoOnce が別々（`bRestartClosed`・`bLastCheckpointClosed`・`bQuitClosed`）。どの道も最後は `BeginLeaving`: カーソルを消し、Fade Out を再生し、押した時刻から 1 s（`LeaveDelay`）後の予定を入れる（クリックはティックの間に来るので、予定の起点 `StepTime` をいまの `Elapsed` にする）。1 s 後の `OpenLevel` は `SetInputMode_GameOnly` の後に `UGameplayStatics::OpenLevel`。
- **ホバー**: 各ボタンの OnHovered で `ColorAndOpacity` を白、OnUnhovered で本家の `Unhover Color`（0.114583）。Death のアニメが LAST CHECKPOINT と QUIT の色を動かしている間（ボタンが出てから 1.5 s）は、毎ティックのアニメがホバーの色を上書きする（本家のアニメも同じ）。
- **RESTART**（`PressRestart`）: `UWasamiPopUpWidget` で「ARE YOU SURE YOU WANT TO RESTART?」（Frame 0、Z 5）を出し、YES を `RestartEvent` に結ぶ。`RestartEvent`: ポップアップの `CloseAnimation`、本家の `Reset Game Instance` と `Reset Lives`（回収の記憶を空に、ライフ 3）→ DoOnce → セーブの `Hospital` を空の欄にして書く（本家の `levelStruct[レベル] = levelStruct[10]`）→ 1 s 後に回収の記憶を空にして今のレベルを開く（チェックポイント 0 なので、Zone 1 は到着の 4、Zone 2 は Zone 1 を開く。06 記録）。
- **LAST CHECKPOINT**（`PressLastCheckpoint`）: ゲームモードのセーブが無ければ何もしない（本家は `SaveSlot` を読めなければ止まる）。`bLastCheckpointWarning` が真ならすぐ先へ、偽なら「Obtaining S Rank is not possible with Last Checkpoint.\r\n \r\nContinue anyway?」（Frame 2、Z 10）と選択音（1.0）。YES（`LastCheckpointEvent`）で警告を真にして書く。先へ: DoOnce → 1 s 後にライフ 3 で今のレベルを開く（回収の記憶は残る）。警告のポップアップは閉じず、開き直すまで黒くなる死亡画面の上に残る（本家どおり）。
- **QUIT TO TITLE**（`PressQuitToTitle`）: DoOnce → 回収の記憶を空に → 1 s 後。本家は `TitleScreen` を開くが、タイトル（作業一覧の項目 17）ができるまでは、その NEW GAME の代わりにライフ 3・セーブの `Hospital` を空にして Zone 1（`AWasamiGameMode::Zone1LevelName`）を開く。
- 本家の `Used Hard Respawn?`・`Hard Check Point`・`Game Instance Time`（リザルトと入口のもの）は持たない（下の「既知の制約」）。

### YES / NO の問い（`UWasamiPopUpWidget`）

### アニメ（`ApplyAnimations`）
キーは本家の書き出しのまま（ティックは毎秒 60000、値、入る・出る接線）を `FRichCurve` の Cubic・Break 接線にする（`WasamiWidgetAnimation::MakeCurve`）。再生し終えたアニメは最後の値のまま止める（下の「既知の制約」）。
- Fade In / Fade Out（1 s）: `Button_0` の α。Fade In は 1 → 0（出口の接線 −3.3758e-5/tick = −2.0255/s で、半ばでもまだ 0.7 を超える黒）、Fade Out は 0（入口の接線同じ。0.35 s ほど 0 未満に沈み、描くときは 0 に切る）→ 1（59999 tick）。
- Shake（1 s）: `Image_161` の α 0 → 1（0.1 s）→ 0.3（0.25 s）→ 0（1 s）と描画の拡大 1.25 → 1.1（0.1 s）→ 1（1 s）、ルートのキャンバスの平行移動 x 0（0.1 s）→ 10 → −5 → 0（0.3 s）・y 0 → −10 → 5 → 0、ライフのアイコンの緑と青 1 → 0（0.1 s）→ 1（0.3 s）（赤と α は 1）。
- Death（3.5 s）: 見出しの α 1 → 0（0.5 s）、YOU ARE DEAD の α 0（0.5 s）→ 1（2.5 s）、ボタンの文字の α 0（0.5 s）→ 1（2.5 s）（RESTART と QUIT の文字は 0.5 s まで触らない）、`VerticalBox_161` の描画の不透明度（0.5 s から）0 → 1、LAST CHECKPOINT のボタンの α 0（0.5 s）→ 1（2.5 s、接線 0.4/s）、QUIT のボタンの α 0（1 s）→ 1（2.5 s）、ヒントの描画の不透明度 1 → 0（0.5 s）。本家の Death の「Restart」の名で作ったトラックは `LastCheckpoint` に結ばれていて、RESTART のボタン自身の α は動かない（1 のまま）。

### SAVING PROGRESS（`UWasamiSavingWidget`）
- 木: `CanvasPanel_0` の右下（アンカー (1, 1)、揃え (0, 0)、自動の大きさ）に `TextBlock_232`「SAVING PROGRESS」（`RobotoTiny` の `Light` 24〈UMG の既定の大きさ〉、左 −300・上 −60）と `Throbber_207`（1 片、横・縦の動きは偽、不透明度の明滅は UMG の既定のまま、`SphereRenderHeightMap` 25 × 25、左 −332・上 −56）。どちらも `RenderOpacity` 0 から。

## 既知の制約・注意点
- **アニメの区間の `RestoreState` は、再生し終えたときに戻さない**。戻すと Fade In の後に黒い覆いが戻り、YOU ARE DEAD も消えるが、WebGL 版 10 記録は本家の収録でゲームオーバーのボタンの色（実測 70）を測っており、画面は見えている。タブレットの Count Shake（03 記録）は終わりに戻しているので、UE 4.24 の本当の振る舞いはどちらかが違う（見た目の詰めは作業一覧の項目 28）。
- 声は鳴らさず長さだけ待つ（項目 20 が表を声そのものに置き換える）。ゲームオーバーの Bierce の台詞と 1.25 s 後の笑い声も項目 20。
- ヒントと声は死ぬたびに無作為（本家の「選んだ番号」の記憶はウィジェットの一時変数で、死亡画面は毎回作り直されるので 1 回の中でしか効かない）。
- 本家のゲームステートの `Lives Lost` +1 と、ゲームオーバーの `Virtual Cursor`（ゲームパッド）は写していない。Easy の分岐（ライフ 0 でも `Life Animation` だけで止まる）と熊のレベルの声は作らない。
- ゲームオーバーのボタンは本家の `Used Hard Respawn?`（LAST CHECKPOINT で真、RESTART・QUIT で偽）と `Game Instance Time`（LAST CHECKPOINT で今の時刻を足す）を持たない。どちらもリザルト（作業一覧の項目 14）が数えるときに足す。`Hard Check Point` は入口だけの仕組みで作らない。
- QUIT TO TITLE はタイトル（項目 17）ができるまで、Zone 1 を最初から開く代わりの道（ライフ 3・セーブの病院の欄を空に）。項目 17 で `OpenLevel('TitleScreen')` に戻す。
- `helvetica-normal_Font` の Default を helvetica の面にしている（本家は Default がエンジンの Roboto、helvetica は en-US の副書体。`dd_assets.font` の説明）。
- `Tips` の `Light` は RobotoTiny に無ければ Slate が最初の書体に落とす。
