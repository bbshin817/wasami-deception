# 画面（死亡画面）

## 役割
ゲームの流れの画面。いまは**死亡画面**（本家の最新版 `pak_reference_2` の `Blueprints/UMG/UMG_DeathScreen`）だけ: 黒地にライフの列、REMAINING LIVES とヒント、その上の黒い覆いの Fade In / Fade Out、失ったライフが赤く揺れて列から消える Shake。ライフが 0 なら YOU ARE DEAD と 3 つのボタン（RESTART / LAST CHECKPOINT / QUIT TO TITLE。押した後はまだ無い）。ライフが残っていれば、終わりにプレイヤーのパワーをリセットして今のレベルを開き直す。タイトル・ポーズ・SAVING PROGRESS・脱出の画面・字幕はこれから。原作の流れの調べは `.claude/references/game-flow/README.md` の「死亡画面」。

画面を足してゲームを止める側（本家のレベル BP の `DeathEvent`）はまだ無い（作業一覧の項目 5 のステップ 5 でゲームモードに足す）。

## 公開インターフェース
- `UWasamiDeathScreenWidget`（`UUserWidget`。C++ で木を組む。ブループリントは無い）
  - `Show(WorldContext, Level)`（静的、BlueprintCallable）… 本家のレベル BP の `DeathEvent` が画面にすること: 最初のプレイヤーのために作り、`Level` を入れ、Z `ViewportZOrder`（5）で足して `SetGamePaused(true)`。作った画面を返す（プレイヤーコントローラーが無ければ null）。
  - `Level`（`uint8`、既定 `AsylumLevel` = 7）… 本家の `Level`（`Enum_Levels`）。画面を足す前に入れる。死亡の台詞の選び分け（`TrapsLevel` = 4 / `AsylumLevel` = 7）。
  - `OnRespawn`（`FWasamiRespawnSignature`）… 本家の `Respawn Event`。ライフが残っているとき、Fade Out の 2 s 後、パワーのリセットの後・レベルを開き直す直前に流す。
  - `Begin(LivesLeft, VoiceSeconds, bHasCheckpoint)` … Construct の時間の流れを 0 から始める。`NativeConstruct` がゲームの側（下）の後に呼ぶ。テストはこれだけを呼ぶ。
  - `Advance(DeltaSeconds)` … 遅延とアニメを進める。`NativeTick` が呼ぶ。
  - 確かめ用: `GetElapsed`・`GetCoverAlpha`（Button_0 の黒の α）・`GetShownLives`（列に並ぶライフの数）・`IsGameOver`・`AreButtonsShown`・`HasRespawned`・`GetTip`。
  - 静的: `ProceedTime(VoiceSeconds)`（Fade Out の始まり = 0.5 + min(声, 6) + 0.5）、`VoiceLengths(Level)`、`TipsFor(LevelName)`、アニメの曲線 `EvaluateFadeIn`・`EvaluateFadeOut`・`EvaluateShakeVignetteAlpha`・`EvaluateShakeVignetteScale`・`EvaluateShakeTranslation`・`EvaluateShakeLifeTint`。
  - 定数: `RevealDelay` 0.5・`FadeInSpeed` 1.5・`ShakeDelay` 1・`VoiceLimit` 6・`ProceedDelay` 0.5・`RespawnDelay` 2・`GameOverDelay` 0.25・`ButtonsDelay` 2・`LifeLostVolume` 0.6・`GameOverVolume` 0.7・`LifeIcons` 6・`FadeLength` 1・`ShakeLength` 1・`DeathLength` 3.5・`UpdateLifeTime` 0.1。
  - 素材（ソフト参照の UPROPERTY。`RebuildWidget` で読む。00 記録の決まり）: `LifeTexture`・`DeadTexture`・`VignetteTexture`・`HeadingFont`・`MenuFont`・`TipFont`（エンジンの `/Engine/EngineFonts/RobotoTiny`）・`LifeLostSound`・`GameOverSound`。
- ツールセット `WasamiDDTools.import_dd_ui()`（01 記録）… `dd_ui.import_all()`。

## 内部構造と処理の流れ

### ウィジェットの木（`BuildScreen`）
本家の `CanvasPanel_0` の子を、本家のスロット（`CanvasPanelSlot` のアンカー・オフセット・揃え・自動の大きさ）のまま同じ順に置く（順が描く順）。UE5 のキャンバスも伸ばしたアンカーでは揃えを使わず、オフセットを余白として扱うので、値を写すだけで同じ位置になる。
1. `Button_22`（`UBorder`、黒。アンカー全面、各辺 −25 px はみ出す。入力を取らないので本家のボタンの黒い地を枠で置き換えた）の中央に `HorizontalBox_114`、その中に `Life1`〜`Life6`（`life_icon_02` を 100 × 100、周りに 10 px、中央揃え）。
2. `VerticalBox_161`（アンカー下端の中央、上へ 358.19 px、揃え (0.5, 0)、自動の大きさ）に `Restart`・`LastCheckpoint`・`QUITTOTITLE`（本家の縦並びの順。`UButton`、`BackgroundColor` の α 0〈RESTART と LAST CHECKPOINT は (86, 86, 86, 0)、QUIT は (1, 1, 1, 0)〉、`ColorAndOpacity` 0.114583、`HitTestInvisible`、周りに 10 px）。中の文字は `helvetica-normal_Font` 30、色 0.520833 の α 0、「RESTART」「LAST CHECKPOINT」「QUIT TO TITLE 」（後ろの空白も本家どおり）。
3. `TextBlock_149`「REMAINING LIVES:」（`helvetica-neue-bold_Font` 50、中央揃え。アンカー上端の中央、下へ 308.40 px、揃え (0.5, 0)）。
4. `YouAreDead`（`you_are_dead` を 1285 × 301、α 0、描画の拡大 1.05。中央から上へ 30.28 px、揃え (0.5, 0.5)）。
5. `Tips`（`RobotoTiny` の `Light` 24、色 0.619792、中央揃え。中央から右 2.54・下 161.33 px、揃え (0.5, 0)）。
6. `Button_0`（`UBorder`、黒。全面、左 −49.55・上 −76.58・右 −43.54・下 −82.58 px はみ出す。Fade In / Fade Out の相手）。
7. `Image_161`（`T_Vignette` を 1920 × 1080、色 linear (0.380208, 0, 0)、α 0。全面、右 1.92・下 1.08 px 内側）。

### Construct（`NativeConstruct`）
- ゲームインスタンスの `DecrementLives` → 残りのライフ。ゲームモードのセーブ（`GetSave()`）の `Hospital.Deaths` +1・`CurrentStreak` = 0 を `WriteSave`。`LevelCheckpoint` > 0 を LAST CHECKPOINT を出す条件として持つ。
- ヒント: `TipsFor(GetCurrentLevelName)` から無作為に 1 つ。Zone 1（名前に `Zone1`）は 3 本、Zone 2（`Zone2`）は 4 本、ほかは「Try not to die next time.」。文言は本家の `Set Tip` のまま（後ろの空白も）。
- 声: `VoiceLengths(Level)` から無作為に 1 本の長さ（本家の Bierce の台詞の `Duration`。Traps 7 本・Asylum 4 本）。**鳴らさず、その長さだけ待つ**（声は作業一覧の項目 20）。
- `Begin(残り, 声の長さ, チェックポイントの有無)`。

### 時間の流れ（`Begin`・`Advance`・`RunStep`）
本家の Delay を「いつ・何をするか」の予定（`Pending`）で持ち、`Advance` がアニメを先に進めてから、期限の来た予定を早い順に走らせる（UE のユーザーウィジェットはアニメの後に遅延を処理する。遅延が始めたアニメは最初のコマをすぐ描く）。予定の遅延は、その予定が来るはずだった時刻から数える。時刻は `Begin` からの秒で、ウィジェットのティック（ゲームを止めていても進む実時間）で進む。
- 0.5 s（`LifeLost`）: ライフ > 0 なら `Life_Lost`（0.6）。
- 0.5 s（`Reveal`）: Fade In を 1.5 倍速で。
  - ライフ > 0: 声の長さの後と 6 s 後に `Proceed`（DoOnce）。`Life Animation`（添字 `ライフ + 1`〜5 のアイコンを列から外し、外したら 1 s 後に `Shake`。ライフ 5 以上なら何もしない）。
  - ライフ 0: チェックポイントが無ければ LAST CHECKPOINT を外す。ライフの列・見出し・ヒントを隠し、0.25 s 後に `GameOver`。
- `Shake`: Shake を再生し、0.1 s のイベントで `Update Life`（添字 `ライフ` のアイコン = 失った 1 つを外す。列は中央に詰まる）。
- `Proceed`: 最初の 1 回だけ。ライフ > 0 なら 0.5 s 後に `FadeOut`。
- `FadeOut`: Fade Out を再生し、2 s 後に `Respawn`。
- `Respawn`: プレイヤーの `GetPowers()->ResetPowers()`、`OnRespawn`、`OpenLevel(今のレベルの名前)`。ワールドが無い（テスト）ときは `OnRespawn` だけ。
- `GameOver`（0.75 s）: `66_-_Game_Over`（0.7）、Death を再生、`SetInputMode_UIOnlyEx`（この画面にフォーカス、マウスは閉じ込めない）、2 s 後に `Buttons`。
- `Buttons`（2.75 s）: RESTART・QUIT TO TITLE と（残っていれば）LAST CHECKPOINT を `Visible`、マウスカーソルを出す。

### アニメ（`ApplyAnimations`）
キーは本家の書き出しのまま（ティックは毎秒 60000、値、入る・出る接線）を `FRichCurve` の Cubic・Break 接線にする。再生し終えたアニメは最後の値のまま止める（下の「既知の制約」）。
- Fade In / Fade Out（1 s）: `Button_0` の α。Fade In は 1 → 0（出口の接線 −3.3758e-5/tick = −2.0255/s で、半ばでもまだ 0.7 を超える黒）、Fade Out は 0（入口の接線同じ。0.35 s ほど 0 未満に沈み、描くときは 0 に切る）→ 1（59999 tick）。
- Shake（1 s）: `Image_161` の α 0 → 1（0.1 s）→ 0.3（0.25 s）→ 0（1 s）と描画の拡大 1.25 → 1.1（0.1 s）→ 1（1 s）、ルートのキャンバスの平行移動 x 0（0.1 s）→ 10 → −5 → 0（0.3 s）・y 0 → −10 → 5 → 0、ライフのアイコンの緑と青 1 → 0（0.1 s）→ 1（0.3 s）（赤と α は 1）。
- Death（3.5 s）: 見出しの α 1 → 0（0.5 s）、YOU ARE DEAD の α 0（0.5 s）→ 1（2.5 s）、ボタンの文字の α 0（0.5 s）→ 1（2.5 s）（RESTART と QUIT の文字は 0.5 s まで触らない）、`VerticalBox_161` の描画の不透明度（0.5 s から）0 → 1、LAST CHECKPOINT のボタンの α 0（0.5 s）→ 1（2.5 s、接線 0.4/s）、QUIT のボタンの α 0（1 s）→ 1（2.5 s）、ヒントの描画の不透明度 1 → 0（0.5 s）。本家の Death の「Restart」の名で作ったトラックは `LastCheckpoint` に結ばれていて、RESTART のボタン自身の α は動かない（1 のまま）。

## 既知の制約・注意点
- **アニメの区間の `RestoreState` は、再生し終えたときに戻さない**。戻すと Fade In の後に黒い覆いが戻り、YOU ARE DEAD も消えるが、WebGL 版 10 記録は本家の収録でゲームオーバーのボタンの色（実測 70）を測っており、画面は見えている。タブレットの Count Shake（03 記録）は終わりに戻しているので、UE 4.24 の本当の振る舞いはどちらかが違う（見た目の詰めは作業一覧の項目 28）。
- 声は鳴らさず長さだけ待つ（項目 20 が表を声そのものに置き換える）。ゲームオーバーの Bierce の台詞と 1.25 s 後の笑い声も項目 20。
- ヒントと声は死ぬたびに無作為（本家の「選んだ番号」の記憶はウィジェットの一時変数で、死亡画面は毎回作り直されるので 1 回の中でしか効かない）。
- 本家のゲームステートの `Lives Lost` +1 と、ゲームオーバーの `Virtual Cursor`（ゲームパッド）は写していない。Easy の分岐（ライフ 0 でも `Life Animation` だけで止まる）と熊のレベルの声は作らない。
- 3 つのボタンは出るだけで、押しても何もしない（ステップ 6）。ホバーの色も無い。
- `helvetica-normal_Font` の Default を helvetica の面にしている（本家は Default がエンジンの Roboto、helvetica は en-US の副書体。`dd_assets.font` の説明）。
- `Tips` の `Light` は RobotoTiny に無ければ Slate が最初の書体に落とす。
