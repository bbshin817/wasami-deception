# Dark Deception 参考資料

原作『Dark Deception』(Glowstick Entertainment)の用語・人物・ステージ・仕組み・演出をまとめた資料。
WASAMI DECEPTION で原作由来の表現(アイテム名、UI 文言、台詞の言い回し、演出)を扱うときに、意味と背景を確かめるために使う。

- 本作の実装の説明ではない(それは `.claude/implementation-records/`)。`records:check` の同期対象外なので、本作の実装が変わったら `07-wasami-mapping.md` を手で直す。
- 本作は非公式のファン作品で、原作のロゴとキャラクターのモデルは使わない方針(オブジェクトとステージのモデルは使ってよい。`.claude/guides/original-fidelity.md` の「原作の素材の使用範囲」)。この資料は原作の素材そのものは含まない。

## 作成方法

2026-09-11 に deep-research ワークフロー(Run `wf_3afddf04-c43`)で作成した。

1. 5 つの観点(用語とステージ一覧、敵 AI、メカニクス、開発と実装、演出と評価)で Web 検索
2. 20 ソースを取得し、主張を 95 件抽出
3. 重要度の高い 25 件を 3 票の反証検証にかけ、18 件確認・7 件否定
4. 検証を通らなかった残りの抽出(約 70 件)は「未検証」として区別して載せた

## 信頼度の表記

各記述の末尾に付ける。

| 表記 | 意味 | 使い方 |
| --- | --- | --- |
| **[A]** | 一次情報(Steam ストアページ、開発元のパッチノートや告知)で確認 | 仕様・数値の根拠にしてよい |
| **[A′]** | 一次情報の原文だが、反証検証は未実施 | 文言の引用には使える |
| **[B]** | 二次情報(Fandom wiki、TV Tropes)で、3 票の反証検証を通過 | 根拠にしてよいが「wiki 値」と明記する |
| **[C]** | 二次情報からの抽出のみ(検証していない) | 表現・雰囲気の参考まで。数値の根拠にしない |
| **[×]** | 検証で否定された | 使わない。どこが誤りかは `sources.md` |
| **[推測]** | 本資料の作成者による推測や観察(ファイル名からの推測など) | 事実として引用しない |

注意点:

- 出典の大半はファン wiki。wiki の数値は開発元の公表値ではない。
- 版によって仕様が違う。主な節目は 1.1.2(Ch1 の更新)、1.4(Ch2 の後)、Enhanced 版(2021-09-28、Ch4 と同時)。
- Fandom は直接取得すると HTTP 402 になり、MediaWiki API の wikitext で読んでいる。

## 使い方

- 原作の実データ(`pak_reference/`)があるものは、そちらを最優先の根拠にする。この資料は Web 調査の結果で、実データと食い違えば実データを採る(優先順位と調べ方は `.claude/guides/original-fidelity.md`)。
- 用語を引くときは `06-glossary.md` から入り、詳細ファイルへ進む。
- 実装値の根拠にするのは [A] と [B] だけ。[C] は言い回しや雰囲気の参考にとどめる。
- 情報を足すときは、出典 URL と信頼度を必ず付け、`sources.md` にも出典を追加する。
- 訳語は本資料での便宜的なもので、公式の日本語訳ではない。ゲーム内表記は英語のまま使う。
