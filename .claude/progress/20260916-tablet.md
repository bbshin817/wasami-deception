## 決定事項

- 2026-09-16: 原作の `Scene`（カメラの子、(0,0,−94.9577)）を挟むと、タイムラインが入れる相対 Z（−39.70 → −4.32）はカメラから約 1 m 下になり画面に映らない。原作の収録から測った画面上の位置（x 4.8〜31.8 %・y 30.3〜91.0 %、WebGL 版 10 記録）は、**カメラ相対**で (35.399, −21.994, −4.322) に置いたときの計算（x 4.6〜31.5 %・y 30.0〜91.5 %）と合う。よってタブレットはカメラの直下に付け、タイムラインの値をカメラ相対として使う（`Scene` は置かない）。

## 再開時の注意

- **エディタは Claude からは起動できない**。Claude が起こしたプロセスには GPU の出力が 1 つも見えず（ログの `LogD3D12RHI: Adapter has … 0 output[s]`。ユーザーが起動したときは `1 output[s]`）、D3D12 がスワップチェーンを作れずに `DXGI_ERROR_NOT_CURRENTLY_AVAILABLE` で即落ちる。Bash からでも PowerShell の `Start-Process` からでも、モニタを点けてロックを解いた後でも同じだった。**エディタの起動はユーザーに頼む**。起動していれば `Tools/ue_remote.py` と MCP は問題なく使える。
- `editor_cycle.py` の `launch()` は 127.0.0.1:8000 に繋がれば成功と見なすが、この PC は Docker Desktop が同じポートを掴んでいるのでエディタが落ちていても成功を返す。起動の確認は `tasklist` か `Tools/ue_remote.py` で行う。
- C++ のビルドは通っている（`Build.bat wasami_deceptionEditor Win64 Development` → Succeeded）。エディタを開き直した後は `/mcp` で再接続してもらう。
- レベルは両ゾーンとも組み立て直し済み（Zone1 は配置 923・灯 1,120・地図の板 1、Zone2 は配置 819・灯 751・地図の板 1）。いま開いているのは `L_Hospital_Zone1`。PIE は止めてある。
