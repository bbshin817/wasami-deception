# 画面（死亡画面・SAVING PROGRESS・黒のフェード・黒い画面・扉の破壊の鍵・読み込み画面・文の枠・欠片の画面・ステージ OP）

## 役割
ゲームの流れの画面。本家の最新版 `pak_reference_2` の次の 10:
- **死亡画面**（`Blueprints/UMG/UMG_DeathScreen`）: 黒地にライフの列、REMAINING LIVES とヒント、その上の黒い覆いの Fade In / Fade Out、失ったライフが赤く揺れて列から消える Shake。ライフが 0 なら YOU ARE DEAD と 3 つのボタン（RESTART / LAST CHECKPOINT / QUIT TO TITLE。ホバーで白くなり、押すと黒くなってレベルを開く。RESTART と、はじめての LAST CHECKPOINT は先に問う）。EASY でライフが 0 なら、最後のライフが揺れて消えるだけで画面は止まったまま（本家どおり抜け道が無い。2026-09-20 のユーザーの回答）。ライフが残っていれば、終わりにプレイヤーのパワーをリセットして今のレベルを開き直す。
- **YES / NO の問い**（`UI/Main/TitleScreen/UMG_PopUp`）: 画面全体の赤いぼかしの上に、ポーズの窓の枠と問い・YES・NO が拡大しながら現れる。死亡画面の RESTART と LAST CHECKPOINT が使う（タイトル・ポーズでも使う部品）。
- **SAVING PROGRESS**（`UI/Main/UMG_Saving`）: チェックポイントの保存で右下に 3 秒出る文字と丸。
- **黒のフェード**（`Blueprints/UMG/UMG_BlackFade_2`）: 黒い全面が消えていく（か現れる）。ゲームモードがレベルを開くたびに 0.5 秒で黒から明ける。
- **黒い画面**（`Blueprints/UMG/UMG_BlackScreen`）: 黒い全面が 1 秒出て消える。のこぎりの罠に捕まったとき、死ぬ 0.3 s 前に出る（08 記録）。
- **扉の破壊の鍵**（`Blueprints/07_FunPlace/Boss/UMG_07_Boss_Switchbox`）: 扉の上に画面空間で出る F と輪。F を押すたびに輪が赤く埋まって揺れ、埋まると赤い火花が出て消える。扉の破壊（`AWasamiDoorBreak`、11 記録）のウィジェットの部品が出す。
- **読み込み画面**（`UI/Main/UMG_Loading`）: 暗い赤の全面と真ん中のレベルの紋章が 0.5 s で現れ、2.5 s 後に消えていく。Zone 1 の救急車の上（`06_ReachAmbulance`、11 記録）が Zone 2 を開く 2.5 s 前に出す。
- **文の枠**（`UI/Main/UMG_TextPrompt`）: 画面の下に白い 1 行が下から浮き上がって現れ、4.5 s から下へ流れて消える（5 s）。障壁と祭壇を見て左クリックしたときの拒否（08 記録）が出す。
- **欠片の画面**（`UI/01/UMG_01_RingPieceCollect`）: ゲームを止めて、ぼかしと黒い幕の上に欠片の絵が回りながら大きく現れ、下に CLOSE が弾んで出る。CLOSE で逆に戻って消え、ゲームに戻る。Zone 2 の祭壇の全回収の後のクリック（11 記録の `Collected Ring Piece`）が出し、閉じると障壁が壊れる。
- **ステージ OP**（`UI/Menu/UMG_ChapterPortal`。両版で同じ木）: 画面全体のぼかしと薄い赤の上に、真ん中を横切る帯 2 本、左に魔法陣（外の輪・中のルーン・レベルの怪物の頭）、その右に赤い題字。本家は病院の入口 `06_Hospital` の `00_Initial Start` が出す。本作は頭がポーズ画面のワサミ（その赤で染める）、題字がスコア画面の「Stinky Gachimi」。出ると、ぼかしが強まる中でカードが 0.8 s〜2 s で現れ、2 s で題字が 1.5 倍から降りて白く光って画面が揺れ、帯が左へ流れて輪とルーンが逆向きに回り、8.5 s から消えていき、11 s で外れる。Zone 1 の新しい始まり（NEW GAME・RESTART・脱出の後。死んで開き直したときと RESUME では出ない）に、次のティックに出て、その間 10 s プレイヤーが止まる（11 記録の `InitialStart`）。**作っている途中**（作業一覧の項目 30。タイトルからの通しの PIE はこれから）。

出す側はゲームモード（`DeathEvent` が死亡画面、`SaveCheckpoint` が SAVING PROGRESS、`BeginPlay` がフェード。02・06 記録）。タイトル・ポーズ・脱出の画面・字幕はこれから。原作の流れの調べは `.claude/references/game-flow/README.md` の「死亡画面」「SAVING PROGRESS」。

### 時間の流れ（`Begin`・`Advance`・`RunStep`）
本家の Delay を「いつ・何をするか」の予定（`Pending`）で持ち、`Advance` がアニメを先に進めてから、期限の来た予定を早い順に走らせる（UE のユーザーウィジェットはアニメの後に遅延を処理する。遅延が始めたアニメは最初のコマをすぐ描く）。予定の遅延は、その予定が来るはずだった時刻から数える。時刻は `Begin` からの秒で、ウィジェットのティック（ゲームを止めていても進む実時間）で進む。
- 0.5 s（`LifeLost`）: ライフ > 0 なら `Life_Lost`（0.6）。
- 0.5 s（`Reveal`）: Fade In を 1.5 倍速で。
  - ライフ > 0: 声の長さの後と 6 s 後に `Proceed`（DoOnce）。`Life Animation`（添字 `ライフ + 1`〜5 のアイコンを列から外し、外したら 1 s 後に `Shake`。ライフ 5 以上なら何もしない）。
  - ライフ 0 で EASY（最新版の @2539 → @2639: `Get Lives` が 0 で設定の `Difficulty` が 0）: `Life Animation` だけ（列はライフ 1 つ〈失う分〉になり、1 s 後の Shake で消える）で、見出しとヒントは残る。`IsHoldingOnEasy` を真にする。本家の 6 s 後の DoOnce は `Get Lives > 0` で止まり、`Proceed`（声の終わり）はライフがあるときだけ結ぶので、その後は何も来ない（ゲームオーバーの音・Death・入力の様式・ボタン・開き直しが無い）。ゲームは止まったまま、入力はゲームのまま。
  - ライフ 0（NORMAL）: チェックポイントが無ければ LAST CHECKPOINT を外す。ライフの列・見出し・ヒントを隠し、0.25 s 後に `GameOver`。
- `Shake`: Shake を再生し、0.1 s のイベントで `Update Life`（添字 `ライフ` のアイコン = 失った 1 つを外す。列は中央に詰まる）。
- `Proceed`: 最初の 1 回だけ。ライフ > 0 なら 0.5 s 後に `FadeOut`。
- `FadeOut`: Fade Out を再生し、2 s 後に `Respawn`。
- `Respawn`: プレイヤーの `GetPowers()->ResetPowers()`、`OnRespawn`、`OpenLevel(今のレベルの名前)`。ワールドが無い（テスト）ときは `OnRespawn` だけ。

## 既知の制約・注意点
- **アニメの区間の `RestoreState` は、再生し終えたときに戻さない**。戻すと Fade In の後に黒い覆いが戻り、YOU ARE DEAD も消えるが、WebGL 版 10 記録は本家の収録でゲームオーバーのボタンの色（実測 70）を測っており、画面は見えている。タブレットの Count Shake（03 記録）は終わりに戻しているので、UE 4.24 の本当の振る舞いはどちらかが違う（見た目の詰めは作業一覧の項目 28）。
- 声は鳴らさず長さだけ待つ（項目 20 が表を声そのものに置き換える）。ゲームオーバーの Bierce の台詞と 1.25 s 後の笑い声も項目 20。
- ヒントと声は死ぬたびに無作為（本家の「選んだ番号」の記憶はウィジェットの一時変数で、死亡画面は毎回作り直されるので 1 回の中でしか効かない）。
- 本家のゲームステートの `Lives Lost` +1 と、ゲームオーバーの `Virtual Cursor`（ゲームパッド）は写していない。熊のレベルの声は作らない。
- **EASY でライフ 0 の死亡画面は、本家のコードどおり抜け道が無い**（ゲームが止まっていて、Esc の結び付けは止まっている間は動かない。本作も同じで、ゲームを終えるしかない。2026-09-20 のユーザーの回答「本家通り」）。2026-09-19 から 20 までは、その画面の上でだけ Esc でポーズが開く本作の例外があった（02・15 記録）。旧版にはこの分岐が無い（ライフ 0 はいつもゲームオーバー）。
- ゲームオーバーのボタンは本家の `Used Hard Respawn?`（LAST CHECKPOINT で真、RESTART・QUIT で偽）と `Game Instance Time`（LAST CHECKPOINT で今の時刻を足す）を持たない。病院のリザルト（`06_Hospital` の `Escape`。13 記録）はどちらも読まない（読むのはホテルなどほかのレベルの BP）ので、作らない。`Hard Check Point` は入口だけの仕組みで作らない。
- `helvetica-normal_Font` の Default を helvetica の面にしている（本家は Default がエンジンの Roboto、helvetica は en-US の副書体。`dd_assets.font` の説明）。
- `Tips` の `Light` は RobotoTiny に無ければ Slate が最初の書体に落とす。
- **読み込み画面の紋章は、本家の魔法陣の中にワサミのシンボルを入れたもの**（2026-09-19 のユーザーの回答。「シンボルをワサミに、魔法陣的なアセットは本家から流用」）。本家のキャラクターの印（リーパーナースほか）は使わない（`.claude/guides/original-fidelity.md` の「原作の素材の使用範囲」）。紋章は病院（7 番）の 1 枚だけで、ほかのレベルは赤い全面だけになる。
