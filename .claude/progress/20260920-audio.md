## 調べたこと（本家）

### 本家の曲の切り替え（`BP_08_MusicPlayer`。`pak_reference_2/_bytecode/DDeception/Content/Blueprints/08_BearHouse/BP_08_MusicPlayer.txt`）

- 部品: `Regular Music`・`Panic Music`・`Override Music` の `AudioComponent` 3 つ。CDO はどれも `bAutoActivate = false`。変数 `bFadeOut`・`bOverrideMusic`。
- `ReceiveBeginPlay` (@879): `K2_SetTimer(Self, 'Update', 0.5, looping = true)`。
- `Update` (@933) は毎回この順で見る。どの分岐も DoOnce（`Temp_bool_IsClosed_*`）で囲まれ、逆の分岐がその DoOnce を Reset するので、鳴らし直しは遷移の 1 回だけ:
  1. `bFadeOut` が真 → `If Playing Fade Out(Regular Music, 1.0)` と `If Playing Fade Out(Panic Music, 1.0)`（`IsPlaying()` のときだけ `FadeOut(1.0, 0.0, Linear)`）。偽 → その DoOnce を戻して次へ。
  2. `bOverrideMusic` が真 → `Regular.FadeOut(1, 0, Linear)`・`Panic.FadeOut(1, 0, Linear)`・`Override.FadeIn(1, 1, 0, Linear)`。偽 → `If Playing Fade Out(Override Music, 1.0)`。
  3. `Intense Music ?` が真 → `Regular.FadeOut(1, 0, Linear)`・`Panic.FadeIn(1, 1, 0, Linear)`。偽 → `Panic.FadeOut(1, 0, Linear)`・`Regular.FadeIn(1, 1, 0, Linear)`。
- `Intense Music ?` (flags 0x1c420000): `GetAllActorsWithInterface(DD_EnemyInterface)` を回し、`Chasing` が真の 1 体目で真を返す（本家はそこで `PrintString("<名前> IS CHASING")` も出すが、これは要らない）。本作は `IWasamiEnemyInterface` に `Chasing` が無いので、足すか `AWasamiEnemy::IsChasing()`（`WasamiEnemy.h:227`）を回す。
- `FadeIn(FadeInDuration, FadeVolumeLevel, StartTime, FadeCurve)` = (1.0, 1.0, 0.0, Linear)、`FadeOut(FadeOutDuration, FadeVolumeLevel, FadeCurve)` = (1.0, 0.0, Linear)。
